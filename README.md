# Tree Diagram APK

Project Android (WebView) yang memuat `app/src/main/assets/index.html`.

## Cara build
- Lokal: buka folder ini di Android Studio, lalu Build > Build APK.
- GitHub: push ke repo, lalu unduh artifact `app-debug` di tab Actions.

## Mengubah aplikasi
Edit `app/src/main/assets/index.html` untuk mengubah tampilan dan logika.
Edit `app/src/main/AndroidManifest.xml` untuk nama dan izin.
